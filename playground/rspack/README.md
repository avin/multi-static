# Rspack example

Этот playground демонстрирует интеграцию `Rspack` с `multi-static` для быстрой инкрементальной сборки на базе Rust-рантайма.

## Что внутри

- исходники и html лежат в `static/`;
- конфигурация `multi-static` и трансформер — в `configs/`;
- трансформер `configs/transformers/rspack-bundle/` поднимает Rspack через Node API, держит компиляторы в памяти и повторно использует их между запросами;
- любые `.ts`/`.js` файлы, помеченные `// @process`, автоматически собираются Rspack.

## Как попробовать

1. Установите зависимости из `package.json` (так же, как в других примерах playground).
2. Запустите `yarn dev` (или `npm run dev`) — `multi-static` отдаёт готовый бандл, Rspack перестраивает только нужную точку входа и использует внутренний кэш.
3. Выполните `yarn build`, чтобы получить статическую сборку в `build/`.

Примечание: трансформер закрывает компиляторы при завершении процесса, чтобы не оставлять фоновых воркеров Rspack.
