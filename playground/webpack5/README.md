# Webpack example

Этот playground демонстрирует интеграцию `webpack 5` с `multi-static` для инкрементальной сборки модулей.

## Что внутри

- исходники и html находятся в каталоге `static/`;
- конфигурация `multi-static` и трансформера лежит в `configs/`;
- трансформер `configs/transformers/webpack-bundle/` запускает `webpack` через Node API и кеширует компиляторы между запросами;
- файлы `.ts`/`.js`, начинающиеся с `// @process`, автоматически собираются через webpack.

## Как попробовать

1. Установите зависимости из `package.json` (аналогично другим playground-примерам).
2. Запустите `yarn dev` (или `npm run dev`) — `multi-static` отдаёт готовый бандл, а `webpack` пересобирает только нужную точку входа.
3. Выполните `yarn build`, чтобы получить статическую сборку в `build/`.

Примечание: трансформер переиспользует экземпляры компилятора webpack и закрывает их при завершении процесса, чтобы избежать утечек.
